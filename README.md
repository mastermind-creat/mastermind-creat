<details>
<summary><b>▸ Case studies: how the systems were built</b></summary>

<br/>

**01 · Elimu Tech LMS — Multi-tenant education platform**
- **Problem:** Institutions needed one system for course delivery, assessment, and certification.
- **Architecture:** Modular course builder, automated grading engine, JWT-secured REST API, tenant-isolated data model.
- **Result:** Digitized course delivery and automated certification across institutions.

**02 · Sokomtaa — AI neighbourhood marketplace**
- **Problem:** Local commerce was fragmented and discovery was poor.
- **Architecture:** Next.js + Node + PostgreSQL, AI recommendations, neighbourhood-scoped indexing, real-time listings.
- **Result:** Shipped as a live, production AI marketplace.

**03 · Automation &amp; Ops — Removing manual toil**
- **Problem:** Repetitive support and reporting work consumed team time.
- **Architecture:** Python services + Twilio + n8n workflows with API integrations.
- **Result:** 90% response automation and 20+ hours/week saved.

</details>
